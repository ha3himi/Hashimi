# Navid Gardizi Perfume V3

این نسخه برای پروژه اصلی آماده شده است.

## عکس محصولات
عکس واقعی هر عطر را در `assets/products/` قرار بده:
- imagination.webp
- noir-oud.webp
- elan.webp
- velour.webp
- sahar.webp
- pure.webp
- majestic.webp
- oud-mist.webp

یا فقط مقدار `image:` همان محصول را در `script.js` تغییر بده.
اگر عکس پیدا نشود، عبارت «اینجا باید عکس گذاشته شود» نمایش داده می‌شود.

## زبان‌ها
دری، پشتو و English با حفظ RTL/LTR و ذخیره زبان انتخاب‌شده.

## سبد خرید
افزایش، کاهش و حذف کامل محصول اضافه شده است.

## امنیت
این پروژه هنوز Front-end است. امنیت واقعی سفارش و پرداخت فقط با بک‌اند، احراز هویت، اعتبارسنجی سمت سرور، rate limiting، CSRF protection، مدیریت امن secretها، HTTPS و درگاه پرداخت معتبر قابل تضمین است. دکمه سفارش عمداً پرداخت جعلی ایجاد نمی‌کند.
